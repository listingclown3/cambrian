[2026-11-14] README does not mention --cwd, --max-turns, --no-session or --no-memory.
  The README shows `intern -p --json --system2 M -- "task"` and links a Docker workspace doc,
  but the flags a headless caller needs first (--cwd to point at a folder, --max-turns,
  --no-session, --no-memory) appear only in `intern --help`, and the JSON event types only in
  `intern schema`. A short "running Intern from another program" section would have saved time.
